# LoginDeck Edge extension

1. Open Browser extension from Website accounts in LoginDeck, to view the installation tutorial.
2. Open Edge extensions, enable Developer mode and select Load unpacked. Choose the folder shown in step 2 of the tutorial; LoginDeck prepares the files automatically.
3. Keep LoginDeck running and select Check connection in the extension.
4. Submit a username/password form on an HTTPS website. A Save to LoginDeck prompt appears in the top right while connected.
5. Select Save within 15 seconds to send the URL, login and password to LoginDeck. Closing, Not now and expiry discard the pending credentials.

LoginDeck matches the website and actual login identifier. Local account names are remarks: password updates preserve them, and new accounts get names such as Account 1. Results use Website · Operation and disappear after four seconds.

No save prompt appears while disconnected. The toolbar provides connection checking; LoginDeck provides installation and usage instructions. Reload the extension and existing login pages after updating its files.

Common HTTPS username/password forms are supported. QR codes, OTP and multi-page login flows are outside the current scope. Capturing a submission does not establish successful authentication.
