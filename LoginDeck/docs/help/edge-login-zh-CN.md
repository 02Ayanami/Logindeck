# LoginDeck Edge 插件

1. 在 LoginDeck 网站账号页打开“浏览器插件”，直接查看安装教程。
2. 打开 Edge 扩展管理页，开启开发人员模式，点击“加载解压缩的扩展”，选择教程第二步给出的插件文件夹。文件由 LoginDeck 自动准备。
3. 保持 LoginDeck 运行，在插件中点击“检测连接”。
4. 连接成功后，提交 HTTPS 网页中的账号密码登录表单。网页右上角会出现“保存到 LoginDeck？”提示。
5. 15 秒内点击保存才会把网址、登录账号和密码发送到 LoginDeck。关闭、暂不保存或超时都会丢弃待保存内容。

LoginDeck 使用网站与真实登录账号判断新增或更新，账号名称仅为本地备注。更新密码保留备注，新账号自动命名为“账号 1”“账号 2”等。结果按照“网站 · 操作”显示，4 秒后消失。

未连接时不显示保存提示。插件只提供连接检测，安装与使用说明由 LoginDeck 提供。更新文件后需要在 Edge 扩展页重新加载插件，并刷新原登录网页。

支持常见 HTTPS 账号密码表单；二维码、验证码和跨页面两步登录不在当前范围。提交捕获不代表网站验证登录成功。
