# Gemini 视觉识别初步试验

仅使用六张虚构页面，与硅基流动试验图片和判定标准相同；没有上传真实账号信息或操作 QQ。

## Gemini 2.5 Flash 接入结果

兼容接口与原生接口均返回 HTTP 404。原生接口明确说明该模型不再向新用户开放，推荐 Gemini 3.6 Flash。定价页列有模型不代表当前账号可以调用。

## Gemini 3.6 Flash

使用 Google 原生 generateContent 接口、图片输入、JSON Schema 输出、模型默认推理设置。完整原始记录在 `gemini-3.6-run-03/report.json`。

| 场景 | 结果 | 耗时 |
| --- | --- | --- |
| 中文登录 | HTTP 503：服务繁忙，未完成验证 | 8.71 秒 |
| 英文深色登录 | 三个控件定位与页面类型均通过 | 9.97 秒 |
| 扫码登录 | 正确分类，不返回填写坐标 | 10.54 秒 |
| 短信验证码 | 正确分类，不返回填写坐标 | 7.30 秒 |
| 已登录主界面 | HTTP 503：服务繁忙，未完成验证 | 8.47 秒 |
| 注册页面 | 判定为 unknown，不返回填写坐标，符合规则 | 7.99 秒 |

6 次请求中，4 项通过、2 项因服务繁忙待补测，已完成识别的样本没有出现判定失败。4 次有效响应平均约 8.95 秒。不能把 4/4 有效样本通过理解为可靠性或准确率已经得到充分验证。

英文登录页的用户名框、密码框、登录按钮预测框与真实框交并比分别为 0.700、0.931、0.886，预测中心均在对应控件内。请求均使用严格 JSON 模式，没有格式降级。

## 与之前试验的比较

- Qwen3.5-4B 第二轮：6 次均返回，2 项满足完整判定条件，两个正常登录样本均无法提供完整可用位置，平均约 2.63 秒。
- OpenRouter：首条请求 HTTP 400，未完成识别，不能据此比较模型准确性。
- Gemini 3.6 Flash：已返回的四项全部通过，但另有两次 503，延迟也更长；当前是值得进一步验证的候选，尚不是可交付的自动填写能力。

## 下一步

中文登录与已登录页面补测已通过，接下来扩展不同布局、缩放、主题及真实 QQ 登录界面。生产流程需在 503 或超时时给出明确反馈，识别失败不得继续输入。实际输入密码前仍须遵守本地窗口校验和首次位置确认。

## 两项补测结果

`gemini-3.6-retest-04/report.json` 记录了仅重测上次 503 的两张相同图片，模型、提示词及判定标准未变。

- 中文登录：通过；用户名、密码、登录按钮的交并比为 0.980、0.972、0.972，三个预测中心都在正确控件内。耗时 9.44 秒。
- 已登录页面：正确返回 already_logged_in，三个填写坐标为空。耗时 10.67 秒。

两轮共 8 次请求，6 次有效识别均通过、2 次原始请求因服务繁忙失败。六个固定场景均已获得通过结果，不等于单轮 6/6 稳定成功，更不能推断真实 QQ 的适配与自动填写已完成。该模型可进入真实登录页识别验证阶段。

API 密钥由用户在本机页面输入，不写入报告或日志；本轮结束后已释放测试服务持有的密钥引用。
