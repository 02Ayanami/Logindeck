# 状态转换执行器

QQ 退出测试显示，同一个已录制动作可能在不同运行中保留进程、重建窗口，或替换进程，也可能跳过快速登录页直接进入账密页。把这些运行时行为记录为 `expect_restart` 会使配置依赖一次测试的偶然结果。

schema v3 将 Click 和 Submit 的后继改为 `next_states`。执行器只发送一次动作，随后重新观察应用；同进程页面变化、窗口重建和通过既有应用身份校验的进程替换都走同一条重新绑定路径。运行器只接受配置列出的后继状态，并可在识别到更后的流程状态时跳过已经不需要的中间步骤。

旧 schema v2 在内存中迁移：`next_state` 转为单元素 `next_states`，`expect_restart` 被移除。导出和新录制统一使用 schema v3。

QQ 配置的退出账号步骤允许 `quick_login` 和 `password` 两个后继状态。登录完成条件仍为提交后识别到 `home`，仅填写不构成成功。

验证：

- `autologin-core` switcher contract：23 项通过，包括 v2 迁移、分支后继、跳过中间状态和动作不重放。
- `platform-macos --lib`：46 项通过，1 项既有钥匙串测试忽略。
- 前端：111 项通过。
