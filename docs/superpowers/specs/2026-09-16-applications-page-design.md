# 应用模块页面方案

状态：供整体审阅的页面方案，不代表应用代码已实现。依据同目录 `2026-09-16-applications-module-design-draft.md` 中已确认的产品规则。

## 1. 导航与页面层级

沿用现有侧栏、品牌图标与中英文切换。设置入口固定在侧栏底部。主内容区域在首页、应用账号页和设置子页之间切换。

应用首页 → 点击应用卡片 → 独立账号页 → 点击某账号的“填写／登录” → 任务流程。

“添加应用”和“添加／编辑账号”使用弹窗。AI 配置与使用帮助使用独立子页，避免设置首页过长。不增加关于、维护或常驻技术状态区域。

以现有 800×600 窗口为基本检查尺寸；内容较长时内部滚动，弹窗操作区保持可见。按钮带文字说明，支持键盘焦点和中英文较长文案。

## 2. 应用首页与添加窗口

首页顶部：左侧标题“应用”，右侧主按钮“添加应用”；下方搜索框“搜索已添加的应用”。主体为响应式图标卡片，显示系统图标、应用名称与“2 个账号”等数量。

- 点击卡片进入账号页；卡片更多菜单仅提供“应用信息”和“从首页移除”。移除确认说明“账号和密码会保留，重新添加后可恢复”。
- 空首页显示“添加你要管理登录账号的应用”和添加按钮；搜索无结果时显示“未找到匹配的应用”，可清除搜索。
- 找不到文件的卡片保留并标注“未找到应用”，点击仍进入账号页。
- 添加窗口包含搜索、图标、名称、已保存账号数量、复选框及“已添加”状态；已添加项不可重复选择。底部显示“已选 N 个”“取消”“添加 N 个”。
- “刷新列表”和“手动选择应用”放在添加窗口中。扫描期间显示进度、可取消，失败时给出重试；取消选择不改变首页成员。
- 原来移除或隐藏、有保存账号但文件缺失的条目也可查到，并提供重新定位入口，避免账号被藏死。
- 默认同名项只显示名称；存在重名副本时补充位置帮助选择。验证为同一应用时复用已有记录，不复制账号。

## 3. 应用账号页与账号编辑

顶部为“返回应用”、应用图标和名称，右侧为“添加账号”和应用级更多菜单。返回首页时保留原搜索条件及滚动位置。

主体采用整页账号列表：每行显示账号名称、用户名，右侧是“填写／登录”和更多菜单。主按钮随该账号的自动提交选项变化，不另放重复状态标签。密码不出现在列表。

- 账号更多菜单：复制用户名、复制密码、编辑、删除。复制结果在当前页面轻提示；删除弹窗明确只删除这一条账号，不影响其他账号。
- “应用信息”按需显示版本、位置及重新定位入口；不占用账号页顶部的大块区域。
- 没有账号时显示“为此应用添加第一个账号”。应用缺失时顶部显示“未找到应用”和“重新定位”，只禁用填写／登录，账号管理与复制可用。
- 重新定位必须核验是同一应用；不匹配则说明原因并保留旧关联。

账号弹窗按顺序显示：账号名称（如“工作账号”）、用户名、密码、自动提交登录开关。新建默认关闭自动提交；说明“开启后，填写完成会尝试点击登录；验证码等仍需手动完成”。编辑时密码留空表示不修改，输入新值才替换。保存失败时就地说明，不丢失非敏感表单内容。

## 4. 任务弹窗与人工接管

任务标题包含目标应用和账号名称，例如“QQ · 工作账号”。主体只显示当前阶段和必要说明，底部随状态展示操作。

| 状态 | 主要提示 | 操作 |
| --- | --- | --- |
| 运行中 | 正在打开应用／检查登录页／填写账号 | 取消 |
| 缺少权限 | 说明本次需要的系统权限与用途 | 打开系统设置、继续检查、取消 |
| 需要退出或切换登录方式 | 请在应用中退出当前账号／切换到密码登录 | 继续检查、取消 |
| 可通用执行退出 | 将退出当前账号并为所选账号填写资料 | 确认退出并继续、取消 |
| 首次位置确认 | 标出账号框、密码框、登录按钮，注明是否自动提交 | 位置正确，继续、位置不对、取消 |
| 本机无法识别 | 当前界面无法可靠识别 | 使用 AI 识别、手动复制、取消 |
| AI 未配置或关闭 | 提示需先配置并开启 | 前往 AI 设置、手动复制、取消 |
| AI 上传预览 | 显示待发送图片及服务地址，说明图片接收方 | 发送并识别、取消 |
| 识别或服务失败 | 显示可理解的原因，如“服务繁忙，尚未填写” | 重试、手动复制、取消 |
| 用户切换窗口 | 已停止输入，说明已完成步骤 | 继续检查、手动完成、取消 |
| 已填写 | 账号资料已填写，请在目标应用继续 | 完成 |
| 已提交 | 已点击登录，尚未确认结果 | 完成；需要验证时提示在目标应用完成 |
| 登录成功 | 已确认登录成功 | 完成 |

“手动复制”在当前任务内展开复制用户名、复制密码操作，不自动复制或自动发送按键。“位置不对”停止当前识别结果，提供重新识别或手动复制，不继续使用错误坐标。

退出的确认只有通用识别经过验证且当前目标满足条件时才出现；不为 QQ 增加专属退出路径。已有会话不创建并行多账号实例。

同时仅允许一个任务。重复点击不能创建第二个任务。任务运行中的关闭弹窗等同于取消后续动作；取消不撤销已完成的输入、退出或提交。重试须重查目标和已执行步骤，不能重放未知是否完成的提交。

弹窗在需要人工确认时取得焦点，输入阶段由目标应用保持前台；自身确认过程与用户意外切换窗口要区分处理。用户退出或继续检查之后，也必须重新核验目标窗口，不能只依据旧截图输入。

协议未同意、按钮禁用、验证码等情况不能靠定位正确就继续提交；界面提示用户在目标应用自行处理。程序不代替用户同意服务协议或开启目标应用的记住密码、自动登录选项。

## 5. 设置与 AI 配置

设置首页保留语言、Edge 登录识别，增加简洁的“AI 辅助识别”行：默认关闭的开关、配置状态及“配置服务”入口。开启但尚未配置时进入配置页，配置完整后再启用，避免显示为可用却无法调用。

AI 配置独立页包含返回、服务类型、服务地址、模型名称、密钥输入以及保存、测试连接、使用帮助。

- 自定义中转站是一等入口；地址示例可用用户提供的 `https://api.apikey.fan`，但不能显示“已验证兼容”。官方服务只提供预设，不限制用户修改服务和模型。
- 接口格式属于连接配置；只有实现并验证过的协议才列为选项。具体协议范围仍须在技术方案中确定，不能仅凭地址推断。
- 密钥用密码框输入，已保存时显示“已保存”而不回显；更换服务地址时要求重新输入对应服务的密钥，避免把旧服务密钥发给新服务。
- 保存配置不自动发出推理请求。测试连接由用户主动点击，界面明确反馈测试中、图片与结果格式验证通过、失败原因；测试图片无个人信息。
- 测试通过只代表连接和识别返回可用，不等于该模型适配所有应用。服务或模型变化后旧测试状态失效。
- 使用帮助独立展示填写地址、寻找模型名称、获取密钥及排查错误的步骤；设置首页不展开长篇文档。
- AI 默认关闭，不因本机识别失败自动上传截图，不自动切换服务或付费模型。关闭 AI 不影响本机识别与账号管理。

本轮不再开展模型测试或调用用户中转站。

## 6. 页面验收与尚待收口

页面验收覆盖空列表、搜索、多选添加、移除后恢复账号、缺失应用重新定位、账号弹窗、复制反馈、单任务控制、人工接管、取消与中英文布局。最终再做一轮黑盒功能和页面测试。

已确认的迁移规则：保留全部账号与凭据；有账号且未隐藏的应用进入首页；旧自动提交关闭一次；之后尊重用户新选择。

此文新增的具体按钮位置、任务按钮文案、AI 配置呈现供整体审阅。技术实施计划仍须明确支持的 API 协议、窗口识别与安全输入实现，以及 QQ 实测验收边界。Gemini 通过虚构样本不等于真实 QQ 截图或输入执行已经验证。
