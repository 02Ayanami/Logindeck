### 剩余 P1：真实 Keychain 访问受签名条件阻塞

原生专用虚构凭据探针明确观测保存和删除都返回 `-34018`（缺少 entitlement）。本机 `security find-identity -v -p codesigning` 返回 0 个有效身份。已增加数值 OSStatus 日志、稳定错误码、具体界面提示、签名配置生成脚本和 [签名步骤](../macos-signing.md)。日志不输出密码、凭据引用或查询内容。

需要有效 Apple Development 或 Developer ID Application 身份、匹配私钥和 provisioning profile，才能完成真实签名包的保存、授权、读取、替换、删除与清理验证。设置页检查仅确认声明存在，不能替代系统实际访问校验。本轮未降低 Data Protection Keychain 或 user-presence 保护，也未声称真实凭据闭环已修好。
