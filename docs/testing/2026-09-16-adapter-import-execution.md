# 本地适配导入与桌面执行

## 已接入

应用详情提供“本地应用适配”：选择本地 JSON → 后端校验版本、大小、状态和流程、应用平台及身份 → 展示配置预览 → 用户确认安装。录制器仍是独立本地工具。文件复制到应用数据目录的 `adapters/<application UUID>.json`，不执行上传或自动回放；支持替换和移除配置。使用临时文件写入后重命名；损坏配置明确显示不可用，不静默回退。

可执行配置需要且只允许一个退出流程，以及一个仅依次填写用户名／密码的流程；退出结束状态必须与填写起始状态一致。其他符合 v2 协议的流程可以保存在文件中，但首版桌面不执行自动提交。选择不唯一时显示不支持，不擅自选择流程。

密码账号出现“按配置切换”入口。任务复用单任务互斥、取消和状态心跳：

1. 确认退出并填写的流程。
2. 后端读取选定账号密码；系统授权结束后再次等待用户点击“开始切换并填写”。
3. 核验并唤醒应用、绑定目标进程、识别当前状态。已登录时执行退出流程，已在登录页时直接填写；其他状态停止。
4. 每步观察及操作使用通用 Runner 和 macOS NativeWorkflow。退出流程遇到人工 Challenge 时等待明确继续，并重新核验、激活应用。
5. 完成只报告“已填写”。记录退出操作尝试和观察到登录页的标记；失败时如实提示已退出或可能已退出，不承诺恢复原会话。

任务持有启动时的配置快照；运行期间安装或移除配置不会改变已确认的步骤。记录或账号被修改、取消、应用身份变化、目标歧义及超时均停止，已派发动作不重放。前台检查和输入期焦点监控仍有既有轮询边界。
