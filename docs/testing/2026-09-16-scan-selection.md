# 扫描后管理应用

## 行为

- 空应用库的首次自动扫描和“重新扫描应用”都先发现候选项，进入 `choosing`，不直接写入应用库。
- 已保存应用默认选中，新发现应用默认不选中。单击应用图标卡片切换选择，选中时右下角显示勾号；可搜索、多选、全选/取消选择当前搜索结果，搜索不会清除其它结果中已选的应用。
- 候选项仅显示系统原生应用图标和应用名称。扫描任务按任务 ID 与候选序号读取图标，前端不会接收或提交候选路径和签名。
- 候选集合包含本次发现和已保存的应用；相同平台、Bundle ID 的多个安装位置合并为一个候选项，未被本次发现的手动导入应用仍可在这里取消勾选并删除。
- 只有选择状态发生变化时，“保存更改”才可用并进入 `committing`。后端使用扫描任务 ID 和候选序号，拒绝过期、重复和越界选择；允许空选择，以便一次删除所有应用。前端不提供应用路径、签名或元数据。
- 取消或关闭选择弹窗丢弃候选，不写入数据。提交开始后禁止重复确认和中途取消；后台任务拥有保存操作，不依赖页面持续打开。
- 保存时，新增勾选的应用会加入列表，取消勾选的已保存应用会连同账号一起删除。密码凭证先写入持久化清理队列，再从钥匙串删除；钥匙串临时失败时可重试，不会遗留无主账号元数据。
- 应用列表不再提供隐藏、取消隐藏或“显示隐藏项目”。历史数据库中的隐藏标记不再影响显示，已添加应用统一展示。
- 手动添加只保留导入单个 `.app`；重新关联仍使用同一个 `.app` 选择器。
